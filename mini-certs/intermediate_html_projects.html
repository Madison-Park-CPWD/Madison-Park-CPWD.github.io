Intermediate HTML — Example Demonstrations & Projects

Ways students can show proficiency for each certificate area — pick what fits, or use as a starting point for your own idea.

Semantic HTML Specialist

Basic Proficiency Demonstrations (choose 1):

  • Semantic Tag Matching: Match semantic tags to their appropriate use cases and content types
  • Tag Purpose Quiz: Explain the specific purpose and proper usage of each semantic tag
  • Code Snippet Analysis: Identify where semantic tags should be used in sample content
  • Website Blueprint: Draw a website layout showing where each semantic tag belongs (suitable for MLLs)
  • Oral Explanation: Verbally describe semantic tags and their purposes to teacher

Project-Based Demonstrations (choose 2):

  • Website Makeover: Convert a div-heavy webpage into properly semantic HTML
  • Content Architecture: Plan and build a multi-section webpage using all semantic tags
  • Accessibility Audit: Review and improve the semantic structure of existing webpages
  • Before/After Showcase: Demonstrate the difference between semantic and non-semantic HTML

Multimedia Integration Expert

Basic Proficiency Demonstrations (choose 1):

  • Media Tag Reference: Create a quick reference showing each multimedia tag and its essential attributes
  • Attribute Function Quiz: Explain what each multimedia attribute does (controls, autoplay, poster, etc.)
  • Tag Selection Challenge: Choose appropriate multimedia tags for different scenarios
  • Media Flowchart: Create visual flowchart showing when to use each multimedia element (suitable for MLLs)
  • Oral Explanation: Verbally describe multimedia tags and attributes to teacher

Project-Based Demonstrations (choose 2):

  • Media Gallery: Create a webpage featuring properly configured audio, video, and responsive images
  • Accessibility Champion: Build multimedia content with full accessibility features (captions, alt text, etc.)
  • Performance Optimizer: Compare and implement different image formats and responsive techniques
  • Interactive Media Demo: Create a presentation explaining when and how to use each multimedia tag

Form Builder Pro

Basic Proficiency Demonstrations (choose 1):

  • Form Element Identification: Identify and explain the purpose of each form element and its attributes
  • Attribute Matching: Match form attributes (id, name, for, etc.) to their functions and use cases
  • Input Type Catalog: List and describe different HTML5 input types and when to use each
  • Form Layout Sketch: Draw and label a complete form showing all elements and attributes (suitable for MLLs)
  • Oral Explanation: Verbally describe form elements and their attributes to teacher

Project-Based Demonstrations (choose 2):

  • Complete Form Project: Build a multi-section form using all required elements (fieldset, legend, various inputs, buttons, select menus)
  • Form Usability Expert: Create forms that demonstrate understanding of labels, accessibility, and user experience
  • Input Type Showcase: Build a demonstration page showing all HTML5 input types in action
  • Form Validation Master: Create forms with comprehensive HTML5 validation attributes and error handling
  • Progressive Form Enhancement: Build a form that works without JavaScript but is enhanced with it
