UX, Usability & Accessibility Certificate

Prerequisites: None

Final Goal: Students will evaluate and design software from the perspective of the people who actually use it — including people using assistive technology.

Learning Targets

  • Apply usability research methods to identify real problems in an interface
  • Practice UX/UI design — user research, personas, feedback, design principles, wireframing, and prototyping
  • Explain and apply accessibility concepts, including WCAG, color contrast, screen-reader-friendly coding, ARIA roles, and accessibility testing tools

Proof

Each checkbox represents a proof of understanding. Students must demonstrate proficiency through evaluation, creation, or application.

Usability Testing DESE Standard 6

  • Usability Test – Describe what a usability test is
  • Card Sort – Describe what a card sort is (users organize content into categories to reveal how they mentally group it)
  • Contextual Inquiry – Describe what a contextual inquiry is
  • Test Report (Composite) – Conduct a simple usability test on a real page and write a report identifying the issues found

UX/UI Design DESE Standard 6

  • UX vs. UI – Explain the difference between UX (user experience) and UI (user interface) design
  • User Research – Document a target user's goals, needs, behaviors, and preferences
  • User Persona – Create a user persona based on demographic research and an identified user type
  • Feedback & Usability – Give three reasons why user feedback displayed in a GUI/application makes the application more usable
  • Display Form Factor – Describe design considerations for one display form factor of your choice (e.g. desktop, tablet, mobile)
  • UI Modality – Define one user interface modality of your choice (e.g. graphical, voice, touch, gesture) and give an example
  • Consistency – Define consistency as a design principle
  • Visual Hierarchy – Define visual hierarchy as a design principle
  • Apply Design Principles (Composite) – Apply consistency and hierarchy principles to improve a poorly designed interface
  • Interface Layout – Create a simplified interface layout (a wireframe) for part of a software application using a graphic design tool
  • Storyboard – Build a storyboard of the user interface for a software application
  • Prototype (Composite) – Create a prototype from your interface layout and storyboard

Accessibility DESE Standard 6

Research and identify methods for implementing software accessibility.

  • Why Accessibility Matters – Research and identify at least 2 reasons why making software accessible matters
  • WCAG Definition – Define WCAG (Web Content Accessibility Guidelines) and its levels (A, AA, AAA)
  • Color Contrast – Check the color contrast ratio of a page using a contrast checker, and fix a failing text/background pair
  • Coding for Screen Readers – Write HTML that a screen reader can navigate meaningfully (semantic tags, alt text, labeled form fields)
  • ARIA Role Definition – Define what an ARIA role is
  • ARIA Attribute – Add an appropriate ARIA attribute to a page and explain what it communicates to assistive technology
  • Accessibility Testing Tools (Composite) – Run an accessibility checker (e.g. Buddy or WAVE) on a real page and document what it flagged and how you'd fix it
✅ Overall Proficiency
Describes and applies usability research methods to find real problems, designs interfaces grounded in user research and design principles, and builds pages that are accessible by WCAG standards — checking color contrast, coding for screen readers, using ARIA roles correctly, and verifying work with a real accessibility testing tool.

Success Indicators

Students are ready to build on UX/usability/accessibility fundamentals when they can:

  • Spot a usability problem in an interface without being told to look for one
  • Explain a design decision in terms of the user's goals, not just how it looks
  • Run an accessibility check on their own work before calling it done, as a habit, not an afterthought
  • Explain to another student why a given page would or wouldn't work well with a screen reader

This UX, Usability & Accessibility Certificate treats accessibility as a core design skill, not an add-on — the same rigor applied to usability testing and interface design applies to making sure that design actually works for every user.
