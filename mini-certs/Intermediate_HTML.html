Intermediate HTML Certificate

Prerequisites: Students must complete all Basic HTML certificates before attempting Intermediate level.

Certificate: Semantic HTML Specialist

Learning Goal: Apply semantic HTML tags appropriately to create meaningful document structure

Proficiency Standards:

  • Semantic tags - header: Uses header for introductory content and navigation
  • Semantic tags - footer: Implements footer for page/section conclusions and metadata
  • Semantic tags - main: Applies main for primary page content (one per page)
  • Semantic tags - article: Uses article for standalone, reusable content
  • Semantic tags - aside: Implements aside for tangentially related content
  • Semantic tags - figure: Uses figure with figcaption for images, diagrams, code snippets
  • Semantic tags - nav: Creates navigation sections with appropriate links

Certificate: Multimedia Integration Expert

Learning Goal: Successfully embed and configure multimedia elements in HTML

Proficiency Standards:

  • Multimedia tags - audio: Implements audio with essential attributes (src, controls, autoplay, loop)
  • Multimedia tags - video: Uses video with essential attributes (src, controls, width, height, poster)
  • Multimedia tags - picture: Creates responsive images using picture element
  • Multimedia tags - source, srcset: Implements multiple source options and responsive images
  • Key-value vs unary/boolean attributes: Understands the difference (class="value" vs disabled)

Certificate: Form Builder Pro

Learning Goal: Design and implement functional HTML forms with proper structure and accessibility

Proficiency Standards:

  • Forms - fieldset, legend, action, method: Creates organized forms with proper grouping and submission handling
  • Input tags: Implements various input types with essential attributes
  • id, name, for, list, value: Uses proper form labeling and data handling attributes
  • Button tags: Creates functional buttons with proper types
  • submit, button, reset: Understands different button purposes and implementations
  • Textarea: Uses textarea with essential attributes
  • cols, rows: Controls textarea dimensions appropriately
  • Select and option tags: Creates dropdown menus and selection lists
  • optgroup, selected, value: Groups options and sets default selections
  • Form validation attributes: Implements HTML5 validation (required, pattern, min, max, etc.)

Example Demonstrations & Projects

Ways students can show proficiency for each certificate — pick what fits, or use as a starting point for your own idea.

Semantic HTML Specialist

Basic Proficiency Demonstrations (choose 1):

  • Semantic Tag Matching: Match semantic tags to their appropriate use cases and content types
  • Tag Purpose Quiz: Explain the specific purpose and proper usage of each semantic tag
  • Code Snippet Analysis: Identify where semantic tags should be used in sample content
  • Website Blueprint: Draw a website layout showing where each semantic tag belongs (suitable for MLLs)
  • Oral Explanation: Verbally describe semantic tags and their purposes to teacher

Project-Based Demonstrations (choose 2):

  • Website Makeover: Convert a div-heavy webpage into properly semantic HTML
  • Content Architecture: Plan and build a multi-section webpage using all semantic tags
  • Accessibility Audit: Review and improve the semantic structure of existing webpages
  • Before/After Showcase: Demonstrate the difference between semantic and non-semantic HTML

Multimedia Integration Expert

Basic Proficiency Demonstrations (choose 1):

  • Media Tag Reference: Create a quick reference showing each multimedia tag and its essential attributes
  • Attribute Function Quiz: Explain what each multimedia attribute does (controls, autoplay, poster, etc.)
  • Tag Selection Challenge: Choose appropriate multimedia tags for different scenarios
  • Media Flowchart: Create visual flowchart showing when to use each multimedia element (suitable for MLLs)
  • Oral Explanation: Verbally describe multimedia tags and attributes to teacher

Project-Based Demonstrations (choose 2):

  • Media Gallery: Create a webpage featuring properly configured audio, video, and responsive images
  • Accessibility Champion: Build multimedia content with full accessibility features (captions, alt text, etc.)
  • Performance Optimizer: Compare and implement different image formats and responsive techniques
  • Interactive Media Demo: Create a presentation explaining when and how to use each multimedia tag

Form Builder Pro

Basic Proficiency Demonstrations (choose 1):

  • Form Element Identification: Identify and explain the purpose of each form element and its attributes
  • Attribute Matching: Match form attributes (id, name, for, etc.) to their functions and use cases
  • Input Type Catalog: List and describe different HTML5 input types and when to use each
  • Form Layout Sketch: Draw and label a complete form showing all elements and attributes (suitable for MLLs)
  • Oral Explanation: Verbally describe form elements and their attributes to teacher

Project-Based Demonstrations (choose 2):

  • Complete Form Project: Build a multi-section form using all required elements (fieldset, legend, various inputs, buttons, select menus)
  • Form Usability Expert: Create forms that demonstrate understanding of labels, accessibility, and user experience
  • Input Type Showcase: Build a demonstration page showing all HTML5 input types in action
  • Form Validation Master: Create forms with comprehensive HTML5 validation attributes and error handling
  • Progressive Form Enhancement: Build a form that works without JavaScript but is enhanced with it

Master Intermediate HTML Certification Requirements

To earn the Master Intermediate HTML Certification, students must:

  • Successfully complete ALL intermediate certificates
  • Prerequisites: Must have completed all Basic HTML certificates first
  • Advanced Capstone Project: Build a complete website featuring:
  • Multiple multimedia elements (audio, video, responsive images)
  • Complex, multi-step forms with validation
  • Professional-level accessibility features
  • Performance optimization techniques
  • Code Review Portfolio: Review and provide detailed feedback on 3 peer projects
  • Advanced Tutorial: Create and present a comprehensive tutorial on multimedia or forms for other students

Assessment Notes for Teachers

Prerequisites:

Students should complete all Basic HTML certificates before attempting Intermediate level.

Enhanced Evaluation Criteria:

  • Advanced Functionality: Code demonstrates sophisticated understanding of multimedia and form features
  • Performance Awareness: Shows consideration for file sizes, loading times, and optimization
  • Professional Accessibility: Implements WCAG guidelines and best practices
  • User Experience Focus: Demonstrates understanding of how features affect end users
  • Code Documentation: Includes comments and clear organization for complex implementations

Real-World Applications:

  • Encourage students to build projects that solve actual problems
  • Connect multimedia skills to content creation and storytelling
  • Relate form skills to data collection and user interaction
  • Emphasize professional web development practices
