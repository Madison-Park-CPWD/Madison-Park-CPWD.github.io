Intermediate HTML Certificate

Prerequisites: Students must complete all Basic HTML certificates before attempting Intermediate level.

Semantic HTML Specialist DESE Standard 8

Learning Goal: Apply semantic HTML tags appropriately to create meaningful document structure

Proficiency Standards:

  • Semantic tags - header: Uses header for introductory content and navigation
  • Semantic tags - footer: Implements footer for page/section conclusions and metadata
  • Semantic tags - main: Applies main for primary page content (one per page)
  • Semantic tags - article: Uses article for standalone, reusable content
  • Semantic tags - aside: Implements aside for tangentially related content
  • Semantic tags - figure: Uses figure with figcaption for images, diagrams, code snippets
  • Semantic tags - nav: Creates navigation sections with appropriate links

Multimedia Integration Expert DESE Standard 8

Learning Goal: Successfully embed and configure multimedia elements in HTML

Proficiency Standards:

  • Multimedia tags - audio: Implements audio with essential attributes (src, controls, autoplay, loop)
  • Multimedia tags - video: Uses video with essential attributes (src, controls, width, height, poster)
  • Multimedia tags - picture: Creates responsive images using picture element
  • Multimedia tags - source, srcset: Implements multiple source options and responsive images
  • Key-value vs unary/boolean attributes: Understands the difference (class="value" vs disabled)

Form Builder Pro DESE Standard 8

Learning Goal: Design and implement functional HTML forms with proper structure and accessibility

Proficiency Standards:

  • Forms - fieldset, legend, action, method: Creates organized forms with proper grouping and submission handling
  • Input tags: Implements various input types with essential attributes
  • id, name, for, list, value: Uses proper form labeling and data handling attributes
  • Button tags: Creates functional buttons with proper types
  • submit, button, reset: Understands different button purposes and implementations
  • Textarea: Uses textarea with essential attributes
  • cols, rows: Controls textarea dimensions appropriately
  • Select and option tags: Creates dropdown menus and selection lists
  • optgroup, selected, value: Groups options and sets default selections
  • Form validation attributes: Implements HTML5 validation (required, pattern, min, max, etc.)

Assessment Notes for Teachers

Prerequisites:

Students should complete all Basic HTML certificates before attempting Intermediate level.

Enhanced Evaluation Criteria:

  • Advanced Functionality: Code demonstrates sophisticated understanding of multimedia and form features
  • Performance Awareness: Shows consideration for file sizes, loading times, and optimization
  • Professional Accessibility: Implements WCAG guidelines and best practices
  • User Experience Focus: Demonstrates understanding of how features affect end users
  • Code Documentation: Includes comments and clear organization for complex implementations

Real-World Applications:

  • Encourage students to build projects that solve actual problems
  • Connect multimedia skills to content creation and storytelling
  • Relate form skills to data collection and user interaction
  • Emphasize professional web development practices
