HTML Basic Certificate

HTML Foundation & Structure DESE Standard 8

Learning Goal: Demonstrate understanding of HTML document structure and proper code formatting

Proficiency Standards:

  • Parsing HTML: Can read and interpret HTML code structure
  • Structure of HTML/Correct indentation: Demonstrates proper nesting and indentation practices
  • HTML 5 Skeleton: Can create complete HTML5 document structure (DOCTYPE, html, head, body)

HTML Tag Proficiency DESE Standard 8

Learning Goal: Show proficiency with HTML tag anatomy and basic tag usage

Proficiency Standards:

  • Tags: Understands the concept and purpose of HTML tags
  • Anatomy of an HTML tag: Can identify and explain all parts of HTML tags
  • Opening tag: Recognizes and creates proper opening tags
  • Closing tag: Understands when and how to close tags properly
  • Self-closing tags: Knows which tags are self-closing (br, img, hr, etc.)
  • Attributes: Can implement and explain HTML attributes
  • Content: Knows what goes between opening and closing tags
  • Basic Tags - h1-h6: Can use all heading levels appropriately
  • One h1 per page: Understands semantic hierarchy and accessibility
  • Basic Tags - a: Creates functional links with href and other essential attributes (target, rel)
  • Basic Tags - p: Uses paragraphs for proper text structure
  • Basic Tags - br: Applies line breaks appropriately (not for layout)
  • Basic Tags - img: Implements images with essential attributes (src, alt)
  • Basic Tags - hr: Uses horizontal rules for thematic breaks
  • Basic Tags - div: Understands generic container usage
  • Basic Tags - span: Uses inline containers appropriately

List & Navigation Creator DESE Standard 8

Learning Goal: Create various types of lists and navigation structures

Proficiency Standards:

  • Lists - Unordered Lists: Creates bulleted lists using ul and li elements
  • Lists - Ordered Lists: Creates numbered lists using ol and li elements
  • type, value, start: Uses attributes to customize list numbering and starting points

Table Layout Master DESE Standard 8

Learning Goal: Create complex, accessible tables with proper structure and spanning

Proficiency Standards:

  • Tables - Simple Tables: Creates basic tables with proper table, tr, td, th structure
  • Tables using rowspans: Implements rowspan attribute to merge cells vertically
  • Tables with colspans: Uses colspan attribute to merge cells horizontally
  • Tables with both rowspans and colspans: Combines spanning techniques for complex layouts

Link & Resource Integration DESE Standard 8

Learning Goal: Implement various types of links and external resource connections

Proficiency Standards:

  • Links - for css: Properly links external CSS files using link element with rel="stylesheet"
  • Links - for html: Creates internal and external HTML links
  • href, target, rel: Uses essential link attributes for navigation, targeting, and relationships

Image Integration Specialist DESE Standard 8

Learning Goal: Implement images with proper attributes for accessibility and performance

Proficiency Standards:

  • Image tags - src, alt: Uses img element with essential attributes for functionality and accessibility

Assessment Notes for Teachers

Evaluation Criteria:

  • Functionality: Code works as intended
  • Standards Compliance: Proper HTML5 structure and semantics
  • Accessibility: Appropriate use of alt text, labels, and semantic elements
  • Code Quality: Clean, well-indented, readable code
  • Creativity: Thoughtful application of skills to solve real problems

Flexible Assessment Options:

  • Students can demonstrate proficiency through multiple pathways
  • Projects can be individual or collaborative
  • Allow resubmission after feedback for improvement
  • Consider real-world applications and student interests

Documentation:

  • Students should maintain a portfolio of their work
  • Encourage reflection on learning and problem-solving process
  • Include peer feedback and self-assessment components
