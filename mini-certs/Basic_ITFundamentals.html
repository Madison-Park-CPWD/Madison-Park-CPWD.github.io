IT Fundamentals Certificate

Prerequisites: None

Final Goal: Students will understand the core hardware, networking, security, operating-system, and data-management concepts that sit underneath every piece of software they build.

Learning Targets

  • Explain core cybersecurity concepts (the CIA triad, common vulnerabilities and threats, cryptography basics, ethical hacking) and how they apply to software and networks
  • Explain networking fundamentals — how networks are built, cloud computing, and the server-side components that connect them
  • Classify hardware components and their relationships, and program a simple physical computing device
  • Compare operating systems and use a command-line interface to navigate a file system
  • Explain data management concepts and design a simple relational database, including how it compares to a NoSQL approach

Proof

Each checkbox represents a proof of understanding. Students must demonstrate mastery through explanation, diagramming, or hands-on application.

Cybersecurity & Networking

Research and identify cybersecurity topics.

  • Application-Level Threats – Identify application-level security vulnerabilities and threats
  • Server-Level Threats – Identify server-level security vulnerabilities and threats
  • OS-Level Threats – Identify OS-level security vulnerabilities and threats
  • CIA Triad – Explain the CIA triad (Confidentiality, Integrity, Availability)
  • Threat Map Components – Identify the components of a threat map and what it shows
  • Build a Threat Map – Create a simple threat map for a given scenario
  • Threat Map Analysis – Analyze a threat map to identify cyberattack targets and origins
  • Identification – Define identification as a component of access control
  • Authentication – Define authentication as a component of access control
  • Authorization – Define authorization as a component of access control
  • Cryptography Task – Demonstrate a basic cryptography task, such as encrypting and decrypting a message
  • Cryptography Definition – Define cryptography as the methods used to encode and protect information
  • Cryptanalysis Definition – Define cryptanalysis as the methods used to decode information without the key
  • Ethical Hacking – Research and describe a penetration testing method in the context of ethical hacking
  • Vulnerability Presentation (Composite) – Create a presentation outlining common network vulnerabilities (cyberattacks, identity theft, privacy) and their associated responses

Explain concepts fundamental to networking.

  • Network Purpose & Hardware – Describe the purpose of a network and the functions of its hardware components
  • LAN – Describe a Local Area Network (LAN) and where it's typically found
  • MAN – Describe a Metropolitan Area Network (MAN) and where it's typically found
  • WAN – Describe a Wide Area Network (WAN) and where it's typically found
  • Cloud Computing – Explain cloud computing, and how network topologies and protocols let users, devices, and systems communicate
  • Server-Side Component – Research and identify one server-side networking component of your choice (e.g. firewall, DNS, VPN, proxy, DHCP, FTP, DC, or AD) and explain its purpose
  • Network Functionality Presentation (Composite) – Create a presentation outlining the issues (latency, bandwidth, firewalls, server capability) that impact network functionality

Hardware & Operating Systems

  • Hardware Classification – Classify hardware components by function (CPU, RAM, storage, I/O devices, etc.)
  • Hardware Relationships – Explain how hardware components relate to each other in a computer system
  • Application Hardware Requirements (Composite) – Research and present the hardware requirements for one specific software application area of your choice (e.g. AI, Big Data, Cybersecurity, Game Development, Cloud Technology, Robotics, IoT, Blockchain, or Extended Reality)
  • Physical Computing – Demonstrate programming a physical computing device (e.g. a microcontroller)
  • OS Purpose – Describe the purpose of an operating system
  • Desktop OS – Describe what a desktop operating system is, with a typical example
  • Server OS – Describe what a server operating system is, with a typical example
  • Mobile OS – Describe what a mobile device operating system is, with a typical example
  • OS Comparison (Composite) – Differentiate between desktop, server, and mobile operating systems
  • CLI Definition – Describe what a Command Line Interface (CLI) is
  • GUI Definition – Describe what a Graphical User Interface (GUI) is
  • CLI vs. GUI (Composite) – Differentiate between a Command Line Interface and a Graphical User Interface
  • CLI Navigation – Navigate a file system at the Command Line Interface
  • File Types – Identify the content associated with different file types, and why different file types exist
  • Lossy Compression – Research and describe one lossy compression algorithm of your choice (e.g. JPEG, MP3) and how it works
  • Lossless Compression – Research and describe one lossless compression algorithm of your choice (e.g. ZIP, PNG) and how it works
  • Compression Comparison (Composite) – Compare your chosen lossy and lossless algorithms, explaining which contexts each is better suited for

Data Management & Databases

  • Data Management Concepts – Research and identify data management concepts, and explain the purpose of data management systems
  • Database Planning – Plan a relational database for a given scenario
  • Database Design – Design a relational database (create an ER diagram with tables, keys, and relationships)
  • Schema Implementation – Explain how a relational database's schema is implemented from its design (e.g. using SQL)
  • One-to-One Relationship – Describe a one-to-one table relationship
  • One-to-Many Relationship – Describe a one-to-many table relationship
  • Data Analysis Purpose – Explain the purpose of data analysis
  • Database Queries – Create database queries
  • Data Reports – Generate a data report from a database
  • Data Visualization – Create a data visualization from a database
  • Relational Database Synthesis (Composite) – Explain how planning, design, and implementation come together to produce a working relational database
  • NoSQL Definition – Explain what a NoSQL database is and how it differs from a relational database
  • Relational vs. NoSQL (Composite) – Compare when you'd choose a relational vs. a NoSQL database for a given scenario
✅ Overall Mastery
Explains core cybersecurity and networking concepts, classifies hardware and compares operating systems, navigates a system at the command line, and designs a simple relational database while understanding how it compares to a NoSQL approach.

Success Indicators

Students are ready to build on IT fundamentals when they can:

  • Explain, in plain language, why a given security practice (encryption, access control, a firewall rule) matters
  • Diagram how a request travels across a network from client to server and back
  • Navigate an unfamiliar computer's file system entirely from the command line
  • Design a small relational database from a written description of the data it needs to hold
  • Explain, without looking it up, when a NoSQL database would be a better fit than a relational one

This IT Fundamentals Certificate builds the hardware, networking, security, and data-management foundation that every other certificate in this series assumes — the infrastructure and concepts underneath the code, not the code itself.
