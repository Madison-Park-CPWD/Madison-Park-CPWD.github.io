IT Fundamentals Certificate

Prerequisites: None

Final Goal: Students will understand the core hardware, networking, security, operating-system, and data-management concepts that sit underneath every piece of software they build.

Learning Targets

  • Explain core cybersecurity concepts (the CIA triad, common vulnerabilities and threats, cryptography basics, ethical hacking) and how they apply to software and networks
  • Explain networking fundamentals — how networks are built, cloud computing, and the server-side components (firewalls, DNS, VPN, DHCP) that connect them
  • Classify hardware components and their relationships, and program a simple physical computing device
  • Compare operating systems and use a command-line interface to navigate a file system
  • Explain data management concepts and design a simple relational database, including how it compares to a NoSQL approach

Proof

Each checkbox represents a proof of understanding. Students must demonstrate mastery through explanation, diagramming, or hands-on application.

Cybersecurity & Networking

  • CIA Triad – Define confidentiality, integrity, and availability, and give a real example of a security failure for each
  • Threat Map – Diagram common software and network threats (malware, phishing, denial of service, man-in-the-middle) and the access-control/cryptography measures that defend against each
  • Ethical Hacking Basics – Explain the purpose of penetration testing and how it differs from a malicious attack
  • Network Fundamentals – Explain what a network is, diagram how devices connect (LAN/WAN, topologies, protocols), and explain the purpose of cloud computing
  • Server-Side Components – Define and explain the purpose of a firewall, DNS, VPN, proxy, DHCP, and FTP in a typical network
  • Storage Security Risks – Identify at least 3 risks specific to storing data on a network and how they're mitigated
  • Other: ________________________________

Hardware & Operating Systems

  • Hardware Classification – Classify at least 8 hardware components (CPU, RAM, storage, I/O devices, etc.) by function and explain how they relate to each other
  • Physical Computing – Write a simple program for a physical computing device (e.g., a microcontroller or single-board computer) that reads input or controls output
  • OS Comparison – Compare desktop, server, and mobile operating systems, explaining what makes each suited to its role
  • CLI vs. GUI – Explain the tradeoffs between a command-line interface and a graphical interface, and when each is preferable
  • CLI Navigation – Use command-line commands to navigate a file system, list/move/copy files, and identify file types by extension
  • Compression Comparison – Compare at least 2 compression algorithms/formats and explain the tradeoff each makes
  • Other: ________________________________

Data Management & Databases

  • Data Management Concepts – Explain the purpose of data management and why organizations plan for it deliberately
  • Relational Design – Design a relational database for a simple domain (e.g., a school, a store) with an ER diagram showing tables, keys, and relationships
  • Table Relationships – Explain one-to-many and many-to-many relationships using your own diagram as an example
  • Queries & Reporting – Write basic queries against your database and explain the purpose of data analysis and reporting/visualization
  • NoSQL Comparison – Explain what a NoSQL database is, give an example use case, and compare it to your relational design — when would you choose one over the other?

✅ Overall Mastery
Explains core cybersecurity and networking concepts, classifies hardware and compares operating systems, navigates a system at the command line, and designs a simple relational database while understanding how it compares to a NoSQL approach.

Success Indicators

Students are ready to build on IT fundamentals when they can:

  • Explain, in plain language, why a given security practice (encryption, access control, a firewall rule) matters
  • Diagram how a request travels across a network from client to server and back
  • Navigate an unfamiliar computer's file system entirely from the command line
  • Design a small relational database from a written description of the data it needs to hold
  • Explain, without looking it up, when a NoSQL database would be a better fit than a relational one

This IT Fundamentals Certificate builds the hardware, networking, security, and data-management foundation that every other certificate in this series assumes — the infrastructure and concepts underneath the code, not the code itself.
