CSS Layout Certificate

Prerequisites: Students must complete the CSS Certificate before attempting CSS Layout.

CSS Flexbox DESE Standard 8

  • Applies display: flex to a container to create a flex context Standard 8, Skill 8
  • Controls the main-axis direction with flex-direction (row, column, and their reverse variants) Standard 8, Skill 8
  • Enables multi-line wrapping with flex-wrap Standard 8, Skill 8
  • Aligns items along the main axis with justify-content Standard 8, Skill 8
  • Aligns items and wrapped lines along the cross axis with align-items and align-content Standard 8, Skill 8
  • Controls how items grow and shrink to fill available space with flex-grow and flex-shrink Standard 8, Skill 8
  • Sets an item's initial size with flex-basis (or the flex shorthand) Standard 8, Skill 8
  • Reorders items visually with the order property, independent of source order Standard 8, Skill 8
  • Overrides cross-axis alignment for a single item with align-self Standard 8, Skill 8
  • Spaces items consistently using gap (rather than margins) Standard 8, Skill 8
  • Builds a common flex pattern (e.g. a horizontal nav bar, a centered element, or an equal-height card row) — pick one Standard 8, Skill 8

CSS Grid DESE Standard 8

  • Applies display: grid to a container to create a grid context Standard 8, Skill 8
  • Defines explicit column and row tracks with grid-template-columns and grid-template-rows Standard 8, Skill 8
  • Uses the fr unit to distribute available space proportionally between tracks Standard 8, Skill 8
  • Uses repeat() to avoid repeating identical track definitions Standard 8, Skill 8
  • Spaces grid tracks consistently using gap (row-gap and column-gap) Standard 8, Skill 8
  • Names layout regions with grid-template-areas and places items using grid-area Standard 8, Skill 8
  • Places items by line number or span using grid-column and grid-row Standard 8, Skill 8
  • Aligns content within grid cells using justify-items (row axis) and align-items (column axis) Standard 8, Skill 8
  • Aligns the grid tracks within the container using justify-content and align-content Standard 8, Skill 8
  • Distinguishes explicit vs. implicit grid tracks and controls implicit sizing with grid-auto-rows/grid-auto-columns Standard 8, Skill 8
  • Builds a responsive grid without media queries using auto-fit/auto-fill with minmax() Standard 8, Skill 8
  • Builds a common grid pattern (e.g. a page layout with header/sidebar/main/footer, or a responsive image gallery) — pick one Standard 8, Skill 8

Responsive Design DESE Standard 8

  • Includes the viewport meta tag (<meta name="viewport" content="width=device-width, initial-scale=1">) so mobile browsers render at actual device width Standard 8, Skill 9
  • Writes media queries using @media with min-width/max-width conditions Standard 8, Skill 9
  • Combines multiple conditions in a single media query using logical operators (and, comma for "or", not) Standard 8, Skill 9
  • Sets breakpoints based on where the content or layout breaks down, rather than targeting specific device widths Standard 8, Skill 9
  • Applies a mobile-first approach: base styles target small screens, min-width queries progressively add complexity for larger screens Standard 8, Skill 9
  • Uses relative units (%, em, rem, vw, vh) instead of fixed pixel values for responsive sizing Standard 8, Skill 9
  • Uses clamp(), min(), and max() for fluid sizing that adapts without needing extra breakpoints Standard 8, Skill 9
  • Tests and debugs layouts across breakpoints using the browser dev tools' device toolbar Standard 8, Skill 9

Choosing & Combining Layout Systems DESE Standard 8

  • Chooses appropriate layout methods (Flexbox vs. Grid) based on 1D vs. 2D layout needs Standard 8, Skill 8
  • Combines Flexbox and Grid in the same design for comprehensive layout solutions Standard 8, Skill 8
