Basic HTML — Example Demonstrations & Projects

← Back to Basic HTML Certificate

Ways students can show proficiency for each certificate area — pick what fits, or use as a starting point for your own idea.

HTML Foundation & Structure

Basic Proficiency Demonstrations (choose 1):

  • HTML Reading Quiz: Identify and label the parts of HTML document structure in sample code
  • Structure Matching: Match HTML elements to their proper nesting levels and indentation
  • Skeleton Assembly: Arrange scrambled HTML5 skeleton elements in correct order
  • Visual Diagram Creation: Draw and label HTML document structure (suitable for MLLs)
  • Oral Explanation: Verbally describe HTML structure components to teacher

Project-Based Demonstrations (choose 2):

  • Code Review Challenge: Fix 5 HTML documents with indentation and structure errors
  • Build from Scratch: Create a properly structured HTML5 skeleton with correct indentation
  • Peer Teaching: Explain HTML structure to a classmate using a diagram or presentation
  • Code Analysis: Identify and explain structural problems in sample HTML code

HTML Tag Proficiency

Basic Proficiency Demonstrations (choose 1):

  • Tag Anatomy Flashcards: Create and demonstrate understanding of tag parts using flashcards or digital quiz
  • Attribute Sorting: Sort attributes into key-value vs boolean categories and explain the difference
  • Tag Identification: Label the opening tag, closing tag, attributes, and content in 10 sample tags
  • Visual Tag Map: Create illustrated poster showing tag anatomy with color coding (suitable for MLLs)
  • Oral Explanation: Verbally describe tag components and basic tags to teacher

Project-Based Demonstrations (choose 2):

  • Tag Dissection Lab: Break down 10 different HTML tags, labeling opening/closing tags, attributes, and content
  • Interactive Webpage: Build a single page using all required basic tags (h1-h6, p, br, img, hr, div, span, a)
  • Tag Reference Guide: Create a visual cheat sheet explaining tag anatomy with examples
  • Debug Detective: Fix a webpage where all tags are broken or incorrectly formatted

List & Navigation Creator

Basic Proficiency Demonstrations (choose 1):

  • List Type Comparison: Explain when to use ordered vs unordered lists with examples
  • List Attribute Demo: Show understanding of list attributes (type, value, start) through simple examples
  • Nesting Rules Quiz: Demonstrate knowledge of proper list nesting and structure
  • List Structure Diagram: Create visual representation of different list types and nesting (suitable for MLLs)
  • Oral Explanation: Verbally describe list types and attributes to teacher

Project-Based Demonstrations (choose 2):

  • Navigation System: Build a multi-level website navigation using appropriate list structures
  • Content Organization: Create a webpage that uses both ordered and unordered lists appropriately with custom styling attributes
  • Interactive Menu: Design a functional dropdown or multi-level menu using HTML lists
  • List Styling Demo: Show proficiency of list attributes (type, value, start) through practical examples

Table Layout Master

Basic Proficiency Demonstrations (choose 1):

  • Table Structure Quiz: Identify table elements (table, tr, td, th) and their relationships
  • Spanning Concept Check: Explain how rowspan and colspan attributes work with simple examples
  • Table Planning Exercise: Plan a complex table layout on paper before coding
  • Table Grid Drawing: Create visual grid showing table structure with spanning cells (suitable for MLLs)
  • Oral Explanation: Verbally describe table elements and spanning concepts to teacher

Project-Based Demonstrations (choose 2):

  • Progressive Table Challenge: Build 4 tables of increasing complexity (simple → rowspan → colspan → both spans)
  • Data Visualization: Create a meaningful data table (sports stats, class schedule, etc.) using appropriate spanning
  • Table Accessibility Audit: Improve existing tables with proper headers, captions, and semantic structure
  • Responsive Table Design: Create tables that work well on different screen sizes

Link & Resource Integration

Basic Proficiency Demonstrations (choose 1):

  • Link Attribute Quiz: Explain the purpose and usage of href, target, and rel attributes
  • Link Type Identification: Distinguish between different link types (internal, external, email, CSS, etc.)
  • Resource Linking Basics: Demonstrate understanding of how to link CSS files and other resources
  • Link Connection Map: Create visual diagram showing different types of links and connections (suitable for MLLs)
  • Oral Explanation: Verbally describe link types and attributes to teacher

Project-Based Demonstrations (choose 2):

  • Multi-Page Website: Create a small website with internal navigation, external links, and CSS/resource linking
  • Link Strategy Portfolio: Demonstrate different link types (internal, external, email, phone) with appropriate attributes
  • Resource Management: Build a webpage that properly links to CSS files, other HTML pages, and external resources
  • Advanced Linking: Show proficiency of link attributes (href, target, rel) through practical implementation

Image Integration Specialist

Basic Proficiency Demonstrations (choose 1):

  • Image Attribute Quiz: Explain the purpose and importance of src and alt attributes
  • Alt Text Writing Practice: Write appropriate alt text for various types of images
  • Image Implementation Basics: Show understanding of proper image tag structure and syntax
  • Image Description Gallery: Create visual collection showing good vs poor alt text examples (suitable for MLLs)
  • Oral Explanation: Verbally describe image attributes and accessibility to teacher

Project-Based Demonstrations (choose 2):

  • Image Gallery Project: Create a photo gallery demonstrating proper use of src, alt, and responsive techniques
  • Accessibility Champion: Audit and improve image accessibility across multiple webpages
  • Performance Comparison: Test and demonstrate different image optimization techniques
  • Visual Storytelling: Use images effectively to enhance content while maintaining accessibility standards
